# Mossbrains

Minimal static company website for `mossbrains.com`. The first release establishes the website while the full design overhaul and game input playtesting remain in progress.

Publish from the root of `main` using GitHub Pages. No package installation or build step is required.

Preview locally with `python3 -m http.server 4174 --bind 127.0.0.1` from this directory.

The custom domain is configured only when its DNS dashboard is ready for the change. Mana Weaver's intended `outgrow.mossbrains.com` address is not linked until there is a working destination.
