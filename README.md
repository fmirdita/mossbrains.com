# Mossbrains

Minimal static company website for `mossbrains.com`. The first release establishes the website while the full design overhaul and game input playtesting remain in progress.

Publish from the root of `main` using GitHub Pages. No package installation or build step is required.

Preview locally with `python3 -m http.server 4174 --bind 127.0.0.1` from this directory.

The custom domain is `mossbrains.com`. Mana Weaver's intended `outgrow.mossbrains.com` address is not linked until there is a working destination.

The journal lives at `/journal/`. Article drafts, account configuration, and the static content builder are maintained in the separate Website coordination workspace. Only rendered public pages are committed here. Articles can later link to a full YouTube video and short clips; no social scripts or server runtime are required.
